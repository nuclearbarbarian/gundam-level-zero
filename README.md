# Gundam Level Zero

A defense industrial- and innovation-base benchmark, with Heavyarms-class
production as the stress test. American-led, allied-integrated, China-excluded.
**Not a procurement proposal — a diagnostic + programmatic benchmark.**

## Live MVP

→ **https://nuclearbarbarian.github.io/gundam-level-zero/**

A three-section static page: The Case, the Heavyarms Tech Tree v0.1
(21 gating nodes across 7 research tracks against the *Gundam Level Zero*
threshold), and an Allied Industrial Integration map (16 carded firms across
Step 4 Japan + Korea, with PRC explicit exclusion per NSIBR). Built for
a vibecoding hackathon.

## Status

**Hackathon MVP — research in progress. Not the Phase 3 publication.**

- 28 Source Cards backing the gating band (T6: 13 anchor + 11 Step 4; T7: 4).
- Phase 2 work in `phase-2/` (track memos, Inquisitor reviews) is local-only;

## Design language

[**MechaPDS v0.2**](mvp/handoff/mechapds.md) — the Penney Design System (1940s
American trade-journal revival) integrated with the ARPANET register
(1969–78 BBN completion-report revival). Two registers assigned by surface;
hybrids forbidden; falsifiable honesty condition.
