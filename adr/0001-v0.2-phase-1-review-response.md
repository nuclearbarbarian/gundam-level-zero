# ADR 0001 — MechaPDS v0.2 in response to Phase 1 Inquisitor review

**Date:** 2026-04-18
**Version adopted:** v0.2
**Status:** Accepted

## Context

MechaPDS v0.1 was drafted and locked on 2026-04-18. The Phase 1 Inquisitor review (`--agents 3-1-1 --lens design-system`) surfaced 27 findings: 4 Critical, 18 Major, 5 Minor. Referee adjudicated: 18 MUST FIX, 5 CONSIDER, 4 DISMISSED. See `phase-1-inquisitor-review-2026-04-18.md`.

The critical findings clustered around four categories:
1. Typography / licensing (Plantin web-delivery incompatible with no-backend static site).
2. Honesty condition unfalsifiable; Plate 3 violates it.
3. Typography lock already broken (Plex Mono 500, italic carve-out without closed list).
4. Spec is print-centric; Phase 3 is interactive.

## Options considered

1. **Close Phase 1 as-is, defer fixes to Phase 2.** Rejected — WCAG and licensing issues are load-bearing for the final product and compound if deferred.
2. **Top-three patch only (C12/C13, C14, C8).** Rejected — the governance gap (C18) and mockup-to-spec divergence (C3/C10/C15/C24) would poison subsequent phases.
3. **Full v0.2 addressing all 18 MUST-FIX + cheap CONSIDER items.** Adopted — cheaper now than after Phase 2 implementation starts.

## Decision

Draft MechaPDS v0.2 addressing all 18 MUST-FIX findings and 5 CONSIDER findings. Correct the v0.1 mockup to comply with v0.2 rules. Institute governance (owner, SemVer, ADR format, surface-errors log, review cadence) as part of the spec. Switch working typeface from Plantin to Charter. Correct the Henry Gannett → JQA + bespoke SVG error. Write the missing Integration Points section. Operationalize the honesty condition with a four-step procedure. Add binding accessibility commitments. Add a Web Register section.

## Consequences

**Positive:**
- Phase 2 can begin against a spec that survives Inquisitor-grade review.
- Governance is in place; surface errors now have a documented promotion path.
- Accessibility is a binding commitment, not an afterthought.
- Henry Gannett error fixed before it costs Phase 3 implementation time.
- Mockup now conforms to the rules it demonstrates.

**Negative:**
- v0.2 is a substantial expansion from v0.1 (roughly 2–3× length).
- Several decisions deferred in v0.1 are now locked; future reversals require ADRs.
- Charter is not Plantin; readers familiar with Plantin will notice. Aspirational Plantin path retained.

**Open items (tracked for v0.3 or later):**
- Images and video domain assignment.
- Foreign-script handling (Noto Sans JP) beyond glossary entries.
- SVG interactive-node keyboard handling worked through at the implementation layer during Phase 3.
- Plantin licensing if project acquires Adobe Fonts access.
